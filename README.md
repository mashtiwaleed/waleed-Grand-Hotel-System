# Waleed Grand Hotel System

A console-based Hotel Reservation Management System built with Python.

## Features

- Create hotel reservations
- Multiple room types
- Automatic bill calculation
- Breakfast options
- Restaurant menu
- Swimming pool service
- Gym membership
- Spa service
- Cancel hotel services
- Check-in / Check-out
- Guest rating system
- Change room
- Change guest name
- Transaction history
- Admin panel
- JSON data storage

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- JSON
- File Handling

## How to Run

1. Download the project.
2. Open terminal.
3. Run:

```bash
python hotel_reservation_system.py
